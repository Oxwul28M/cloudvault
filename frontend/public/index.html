    Comandos de Conexión

    Terminal / CLI 
    # Conectar por línea de comandos:
sftp -P 2222 sftpuser@<IP-DEL-VPS>

# Subir un archivo:
put mi_archivo.pdf /uploads/

# Listar archivos:
ls /uploads/

# Descargar un archivo:
get /uploads/archivo.pdf ./local/

    Seguridad Implementada

    • Aislamiento chroot (cada usuario ve solo su directorio)
    • Contraseñas encriptadas con bcrypt
    • Permisos de directorio 755 (propietario: root)
    • Volumen compartido entre backend y SFTP
    • Puerto no estándar (2222) para reducir bots
    • Rate limiting en la API REST
    • JWT con expiración de 8 horas
    • Registro de auditoría de todas las operaciones

    API Node.js + Express (REST API)
    ↓ TCP :5432     ↓ Volumen
    BD PostgreSQL
    SFTP atmoz/sftp :2222
